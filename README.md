# sanity-pte-interpolation

Sanity Portable Text Editor plugin for interpolating values into PTE fields.

## Packages

- [`sanity-plugin-pte-interpolation`](./packages/sanity-plugin-pte-interpolation) — Sanity Studio plugin
- [`pte-interpolation-react`](./packages/pte-interpolation-react) — React consumer library

## Development

```sh
pnpm install
pnpm dev
```
